# Strati — web estática

Landing visual y responsive para Strati, construida únicamente con HTML, CSS y JavaScript sin dependencias.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive, transiciones y animaciones.
- `script.js`: loader, navegación móvil, revelados, selector visual de sabores y parallax.
- `assets/images/`: fotografías optimizadas en WebP y wordmark.

## Probar en local

Abre `index.html` directamente o ejecuta un servidor local desde esta carpeta:

```bash
python -m http.server 8000
```

Después visita `http://localhost:8000`.

## Publicar en GitHub Pages

Sube el contenido de esta carpeta a un repositorio y activa **Settings → Pages → Deploy from a branch**. No necesita compilación ni backend.

## Antes de publicar

Confirma que la dirección, el enlace de Instagram y los textos comerciales son definitivos. Las fotografías utilizadas proceden del material aportado para el diseño.
